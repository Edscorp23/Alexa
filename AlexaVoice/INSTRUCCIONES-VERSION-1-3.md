# Alexa Voice 1.3 — Diseño anime personalizado

Esta versión incorpora la imagen aportada por el usuario como fondo de la interfaz y un ícono ilustrado de aventuras. Conserva las funciones de recordatorios, botón de confirmación y confirmación por voz de v1.2.

## Actualización GitHub

1. Descarga el archivo ZIP **AlexaVoice-v1.3-Proyecto-Completo.zip** y descomprímelo.
2. En tu repositorio GitHub, coloca el contenido de `AlexaVoice` dentro de la carpeta existente `AlexaVoice`, respetando las mismas rutas. No crees una carpeta `AlexaVoice/AlexaVoice` adicional. Las imágenes nuevas van dentro de `AlexaVoice/app/src/main/res/`.
3. GitHub → Actions → última ejecución → Artifacts → descarga el ZIP con `app-debug.apk`.
4. Instálalo como actualización de la app en tu HONOR X8a.

**Importante**: GitHub web no siempre permite sustituir mediante la subida de una carpeta completa. Para actualizar fácilmente, usa GitHub Desktop o el editor web para los archivos de texto; para las imágenes, usa Add file → Upload files navegando a la carpeta correspondiente.

La escucha por voz requiere que la pantalla de la app esté visible. En segundo plano, el botón de la notificación puede requerir desbloquear. No se ha realizado una compilación de verificación local.
